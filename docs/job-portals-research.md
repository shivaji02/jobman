## Implementation Notes

### Automation Approach
- **Easy Portals:** Use simple click + form fill
- **Modal-based (Instahyre):** Use JavaScript to trigger click events and submit forms
- **JavaScript-heavy (LinkedIn, Glassdoor):** Use Puppeteer or Playwright for headless browsing; fallback to manual checks
- **Social/niche (Indie Hackers):** Monitor and manual application

### Dedup Strategy
- Maintain persistent log: `applied_jobs_log.csv` (date, site, job_id, job_url, title, company, status)
- Check before each application to avoid duplicates
- Track "not qualified" / "auto-rejected" reasons to improve filtering

### Success Metrics
- **Target:** 50-100 applications submitted in 2 weeks
- **Expected Response Rate:** 10-20% shortlisted (5-20 interviews)
- **Timeline:** 2-4 weeks to first offer
